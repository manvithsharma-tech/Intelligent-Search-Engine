    Methodological Note on Cross-Algorithm Comparisons

    Score Incommensurability: Absolute numerical scores cannot be directly compared across algorithms (Coverage-Aware TF-IDF produces normalized fractions ∈ [0, 1], BM25 produces unbounded asymptotic log-odds scores ≥ 0, and Baseline TF-IDF sums raw product terms). Latency Differences: Measured response times reflect candidate postings list filtering, scoring passes, and JVM runtime state under local execution rather than asymptotic superiority. Evaluate algorithms based on ranking coherence and query-term coordination rather than raw scores or execution milliseconds.

    Comparative Methodology & Academic Constraints
    Corpus Scope: Google searches billions of public web pages indexed worldwide, whereas our engine searches a curated, fixed academic corpus of 50,000 documents across 11 structured domains.
    Dynamic Factors: Google rankings vary dynamically by geography, device, language localization, real-time index refresh, and search history.
    Latency Nuance: Browser response time (network round-trip, TLS, CDN, DOM render) is fundamentally distinct from local Java backend algorithmic processing latency.
    Academic Fairness: Comparisons must not be claimed as statistically fair benchmarks unless identical corpus ground truth, standardized relevance criteria, and controlled query sets are used.
    Terms of Service & Research Ethics: Google search results are rendered directly by Google in the external browser tab. This application adheres to academic integrity and Google's Terms of Service: we do not scrape, automate, parse, or copy Google search results.

    System Architecture & Core Data Structures

    Technical breakdown for project evaluation and final review

    1. Compressed Trie (Radix Tree)

    Compresses nodes with single descendants into multi-character edge labels. Provides memory-efficient storage of 64,380 vocabulary words and guarantees O(L) time complexity for prefix lookup and real-time autocomplete suggestions.

    2. Inverted Index

    A HashMap mapping every preprocessed dictionary term to a Set of matching document IDs. Fast constant-time candidate filtering prior to vector-space ranking.

    3. Multi-Algorithm Relevance Ranking

    Engineers deterministic result ranking with three selectable models: Coverage-Aware TF-IDF (penalizing partial-match noise with a 1.5 term-coordination exponent), Okapi BM25 (probabilistic relevance with term saturation k1=1.2 and document length normalization b=0.75), and Baseline TF-IDF.

    4. Evaluation Engine

    Evaluates query retrieval quality against labeled ground-truth categories using Information Retrieval metrics: Precision, Recall, and the harmonic mean F1-Score.

    5. Latent Semantic Analysis (LSA) Concept Space

    128-dimensional truncated SVD factorization of the sublinear TF-IDF term-document matrix. Projects documents and queries into a latent concept subspace where synonyms and related terms co-activate. Enables genuine meaning-based retrieval for queries with related meanings but different wording, complete with topic explainability.
